# Cyrillic-Url-Blocker
This is an extension that blocks any website containing even a single Cyrillic character.

# Here’s how to install it:

Download the ZIP file and extract it.

Go to chrome://extensions/

Enable Developer Mode in the top-right corner, click “Load unpacked extension” in the top-left corner, and select the extracted folder.

The installation is now complete.
Enjoy safe web browsing.

# 日本語

これは、キリル文字が1文字でも含まれているすべてのウェブサイトをブロックする拡張機能です。

インストール方法は以下の通りです：

ZIPファイルをダウンロードして解凍してください。
chrome://extensions/ にアクセスしてください。
右上隅で「開発者モード」を有効にし、左上隅の「未圧縮の拡張機能を読み込む」をクリックして、解凍したフォルダを選択してください。
これでインストールは完了です。
安全なウェブ閲覧をお楽しみください。
